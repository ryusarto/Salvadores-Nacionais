# Chupetinha v3

PNGs aprovados de 41 animações de seis quadros e 11 FX de seis quadros, alpha verdadeiro. São as fontes sem perda dos WebP de runtime. Reexporte com `node tools/import-chupetinha.mjs` a partir da raiz do repositório.

Os 82 grupos de geração nativa, correções pontuais, mestres e quadros individuais ficam preservados no kit de produção do Dropbox `Assets/Salvadores Nacionais/chupetinha-v3-6quadros`. O Git contém os atlases finais aprovados, os prompts, modelo/retrato e o contrato. Fotografias de referência não foram publicadas.
